# Network Security Projects

This section contains two networking projects that I keep separate because they were built for different purposes.

## Home Network Security & Traffic Analysis

[View project](./home-network-security-assessment/)

This was a university group project based on a real residential network. I adapted the technical parts for the portfolio and kept the original evidence where possible.

I worked with:

- IPv4 and DHCP
- Gateway and DNS troubleshooting
- Wi-Fi security review
- Wireshark traffic captures
- `ping` and `tracert`
- Basic security findings and recommendations

## Packet Tracer VLSM Network Lab

[View project](./packet-tracer-vlsm-lab/)

This was a Packet Tracer exercise focused more on network design and addressing than on security analysis.

I used VLSM to divide a `10.10.0.0/21` network between six LANs and three point-to-point router links, then configured and tested the topology.

I practiced:

- IPv4 subnetting
- VLSM
- Router interface addressing
- /30 point-to-point links
- Packet Tracer
- Connectivity testing

## Why I keep them separate

The first project shows how I analyze and troubleshoot a real network. The second shows how I calculate and configure a network from the ground up.

They are related, but combining them into one project would make the story less clear.
