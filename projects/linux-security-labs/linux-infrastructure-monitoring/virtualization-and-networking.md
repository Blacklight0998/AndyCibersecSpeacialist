# Virtualization and Networking

## Implemented Lab

The project started by installing and cloning three Linux virtual machines and placing them on the same network.

Each VM was configured with its own static IP address using Netplan. The configuration was validated with Netplan tools and connectivity was tested between machines with `ping`.

## Concepts Practiced

- Linux virtualization
- VM cloning
- Static IPv4 addressing
- Netplan configuration
- Network interface configuration
- Host-to-host connectivity testing
- Troubleshooting basic Linux network configuration

## Why It Matters for Cybersecurity

A large amount of security work depends on understanding how hosts are configured and how they communicate. Static addressing, interface inspection and basic connectivity validation are foundational skills for Linux servers, SOC labs and security testing environments.
