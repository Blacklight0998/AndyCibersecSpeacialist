# 🌐 Network Security Labs

Hands-on networking and traffic-analysis projects adapted to cybersecurity and defensive security practice.

## Projects

### 🏠 Home Network Security & Traffic Analysis

Residential network assessment covering infrastructure, connectivity, Wi-Fi security, performance, packet analysis and security findings.

**Skills:** IPv4 · DHCP · DNS · Wireshark · TCP/IP · Wireless Security · Network Segmentation · Troubleshooting

[View project](./home-network-security-assessment/)

### Packet Tracer VLSM Network Lab

Cisco Packet Tracer practice using VLSM to divide a `10.10.0.0/21` network between six LANs and three point-to-point router links.

**Skills:** VLSM · IPv4 Subnetting · Router Interfaces · Point-to-Point Links · Packet Tracer · Connectivity Testing

[View project](./packet-tracer-vlsm-lab/)

## Purpose

These labs document practical networking knowledge and its application to cybersecurity, including traffic analysis, network visibility, security assessment and troubleshooting.
