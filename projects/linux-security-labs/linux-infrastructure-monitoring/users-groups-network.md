# Users, Groups and Network Inspection

## User and Group Administration

The project included practical exercises for:

- Creating users
- Creating groups
- Adding users to groups
- Modifying group membership
- Reviewing existing users
- Checking active sessions

These tasks reinforce Linux access-control fundamentals and basic privilege administration.

## Network and Service Inspection

The project also used:

- `ip a` to inspect network interfaces and addresses
- `ping` to verify connectivity
- `ss -tunlp` to inspect active TCP/UDP sockets, listening ports and associated services

## Security Relevance

User/group management and listening-port inspection are common parts of Linux hardening and security review. They help identify who has access to a system and what network services are exposed locally.
