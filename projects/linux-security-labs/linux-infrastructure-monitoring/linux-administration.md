# Linux Administration

## Implemented Exercises

The project included a practical command-line section covering common Linux administration tasks.

### File and Directory Management

Commands and concepts practiced included:

- `cp` for copying files
- `mv` for moving and renaming files
- `rm` and `rmdir` for deletion
- `mkdir` for directory creation
- `tar` for compression and extraction
- `less`, `head` and `tail` for file inspection

### Shell and Text Processing

The exercises also covered:

- Adding a directory to `PATH`
- Creating aliases
- I/O redirection with `>` and `>>`
- Pipes with `|`
- `grep` for filtering
- Basic and extended regular expressions
- `find` for locating files
- `xargs` for passing command output as arguments

## Security Relevance

These commands are fundamental for log review, evidence collection, script execution, file inspection and day-to-day Linux administration in cybersecurity environments.
